1. Identité du demandeur

Toutes les polices du document final seront en Times New Roman. Le code social et le nom complet seront chiffrés avec BVE-512 (clé publique cosmétique).

2. Mode de rédaction

Choisissez comment vous allez remplir le document. Vous ne pourrez écrire que sur la moitié inférieure / côté gauche (zone française).

À la main

Dessinez avec le doigt ou la souris. Taille de trait et couleur (bleu / rouge / noir). Maximum une demi-page par page.

Digital

Texte tapé. Police Arial ou Times New Roman. Taille ajustable. Possibilité d’ajouter des pages.

Importer une image (déconseillé — risque de refus)

L’image sera compressée pour tenir sur la moitié de la page. Chaque image = une page.

3. Rédaction du document

Zone d’écriture limitée à la moitié inférieure / côté gauche. Les en-têtes (Français + logo + Celst + métadonnées) sont protégés.

Format A4 (21 × 29,7 cm) — zone d’écriture = moitié inférieure

Image sélectionnée. Elle sera placée sur une page dédiée (moitié inférieure).

La dernière page du PDF contiendra uniquement les infos du document + votre signature à la main. Signez clairement dans le cadre ci-dessous.
